# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator accepts:
- Principal amount
- Rate of interest
- Time period

## Output

The calculator calculates and displays the simple interest and the total amount.

## Technologies Used

- Bash
- Shell scripting

## Usage

Run the `simple-interest.sh` script in a Bash terminal and enter the required values when prompted.
